# 站长重配清单（简述）

> 重构分支不携带个人测试 Cloudflare / GitHub 配置；默认 `wrangler.jsonc` 已改回源站生产配置。
> 以下项目需要在站长账户重新配置或确认。

## Cloudflare

| 资源 | 生产值 |
|---|---|
| Worker | `ze-map-site` |
| D1 | `ze-map-community` |
| KV | `UPLOADS` |
| R2 | `ze-map-terr`（绑定 `TERR`） |
| 域名 | `ze-map.cn`、`terr.ze-map.cn` |

- Workers Builds 连接源仓库 `hhjjdsj/ze-map-site` 的 `main`，构建 `npm run build`，部署 `npx wrangler deploy`。
- 默认 `wrangler.jsonc` 只含生产绑定；不要使用 PR 作者的个人测试 Worker / D1 / KV。
- 上线前先导出旧 D1，再执行 `npx wrangler d1 migrations apply ze-map-community --remote`；确认旧 `submissions` / `difficulty_votes` 导出后再删除。

## Secrets

```text
ADMIN_TOKEN
IP_SALT
GITHUB_TOKEN
GITHUB_OAUTH_CLIENT_ID
GITHUB_OAUTH_CLIENT_SECRET
SESSION_SECRET
TURNSTILE_SECRET（如启用）
```

`GITHUB_TOKEN` 只授权 `hhjjdsj/ze-map-site` 的 Contents 读写；GitHub OAuth callback 为
`https://ze-map.cn/api/auth/github/callback`。不要使用 PR 作者的 token / OAuth App。

## GitHub

- PR 合并到 `hhjjdsj/ze-map-site` 的 `main`。
- 个人 fork / 测试分支不参与生产构建；个人测试 Workers Builds 连接应在切换前断开或删除。
- 生产 Workers Builds 使用源仓库 `main`，不要指向 PR 作者的 fork。

## 验收

```bash
npm ci
npm run build
npm run content:verify-content
npm run test:content
npm run handoff:check
```

抽查 `/maps/ze_cyberspace_v2/`、`/maps/ze_depths/`、`/submit/edit`、`/submit`、`/admin/`、`/api/vote`；审核写回只改 `data/content`。
