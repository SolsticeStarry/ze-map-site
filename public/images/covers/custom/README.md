# 人工封面放这里

放一张图进来，就等于给那张地图换封面（取代脚本渲染的俯视密度图）。

## 规则

**文件名必须正好是「地图英文名」**：

```
ze_obj_abyss_v2.jpg      ✅
ze_obj_abyss_v2.png      ✅
ze_obj_abyss_v2.webp     ✅
2001-ze_obj_abyss_v2-3779264454.jpg   ❌ Steam 分片名，永远不会生效
ze_obj_abyss.jpg         ❌ 拼错了，永远不会生效
```

「地图英文名」= 地图详情页标题下面那行小字 = 网址 `/maps/` 后面那一段。

扩展名**大写也认**（`ze_obj_abyss_v2.PNG` 一样生效，生成器按大小写不敏感找图），但建议统一小写：
线上构建跑在 Linux 上、文件名大小写敏感，小写最不容易出错。

⚠️ 名字写错**不会有任何报错** —— 页面、构建、检查全都正常，只是这张图永远不出现。
所以提 PR 之后请确认自动检查是绿的（`npm run cover:verify` 会核对文件名对不对得上某张真实地图）。

## 图片要求

| | |
| --- | --- |
| 比例 | 横向 16:9（这张图会用在卡片和详情页顶部大图两处，竖图会被裁成中间一条） |
| 宽度 | 1280px 左右最合适，至少 640px |
| 体积 | 300 KB 以内，硬上限 800 KB |
| 格式 | `.jpg` / `.png` / `.webp` 都收，但**截图直接存 PNG 往往有 1~2 MB，会超限** —— 尽量存成 JPG（画质 80 左右），或者用 `npm run cover:set` 让脚本帮你压成 webp（通常只有 1/10） |

## 怎么传（网页上就能做）

1. 本目录右上角 **Add file → Upload files**，把图片拖进去
2. 文件名按上面的规则取
3. **Propose changes** → **Create pull request**

图片是二进制文件，GitHub 的**铅笔编辑对它不可用**，但上传、替换（同名同路径再传一次）、删除都能在网页上完成。

## 想换回脚本渲染的封面

把这里的那个文件删掉即可（文件页面右上角 **⋯ → Delete file**），不需要改任何配置。

完整说明见 [`docs/cover-images.md`](../../../docs/cover-images.md)。
